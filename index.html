Version1

The beginning

Make the page and move Jubee

📂

Start with an empty jubee-world folderChoose Agent in Copilot Chat and give it the prompt below. Copilot creates version-1 and all three game files.

  • Three files made by Copilot
  • Cheerful game page
  • Start button
  • Left and right movement
Prompt to give AI
I opened an empty folder named jubee-world in Visual Studio Code. Please create the first version of a browser game called Jubee World. Create a folder named version-1 inside the open jubee-world folder. Inside version-1, create index.html, styles.css, and game.js, and connect them so the game works when I open version-1/index.html. Make a cheerful page with the game title, a large game area, simple instructions, and a Start Game button. Draw Jubee as a caramel-colored shape with a cream-colored face. Let me move Jubee left and right with the arrow keys or the A and D keys. Jubee should stop when I release a key and stay inside the game area. Please create and fill every file directly. Do not ask me to create a folder, provide files, or paste code. When you finish, tell me how to open and test the game.
What should I test?
  • Check that Copilot created version-1.
  • Check that version-1 contains index.html, styles.css, and game.js.
  • Open version-1/index.html and select Start Game.
  • Hold and release each movement key.
  • Make sure Jubee stays inside the game area.

Version6

Play anywhere

Make the game ready for smartphones

📱

Ask Copilot to create version-6Copilot copies all of version-5 and makes the phone changes only inside version-6.

  • Fits small screens
  • Large touch buttons
  • Two-button play
  • Real-phone testing
What makes it smartphone-ready?
  1. In landscape mode, the game uses the full available screen height without reserving vertical space for controls.
  2. Left and Right sit outside the game at the far-left edge, while Jump sits outside it at the far-right edge.
  3. A player can hold Left or Right while tapping Jump with another finger.
  4. Tapping the game buttons does not move the webpage, highlight words, or make the screen larger.
  5. Music begins after the player taps Start, and all menus can be used by touch.
  6. The GitHub Pages link is tested on at least one real phone.
Prompt to give AI
My open jubee-world folder contains a working folder named version-5. Create a new folder named version-6 by copying every file and folder from version-5. Make all new changes only inside version-6 and do not change the earlier folders. Make version-6 work well on smartphones while keeping the computer controls. Design the phone layout mainly for landscape mode. In landscape mode, make the game screen use the full available height. Do not reserve any space above or below the game for touch controls. Put the Left and Right buttons together outside the game screen at the far-left edge of the phone. Put the Jump button outside the game screen at the far-right edge. Keep the game centered between the controls, preserve its shape, and never place a control over Jubee, enemies, platforms, or any part of the game. I need to be able to hold a direction with one finger and jump with another. Tapping the controls should not move the webpage, select words, or make the screen larger. Double-tapping Jump should still make Jubee jump higher. Start the music only after I tap Start so phone browsers allow it. Keep all ten levels, supplied pictures, sounds, scores, enemies, apple power, and gate actions working. Create or update all needed files directly inside version-6. When you finish, tell me how to test it on a computer and a phone.
What should I test?
  • Check that Copilot created version-6 without changing version-5.
  • Turn the phone sideways and confirm the game uses the available height.
  • Confirm that Left and Right are outside the game at the far left and Jump is outside it at the far right.
  • Hold Left or Right while tapping Jump with a second finger.
  • Double-tap Jump and check the high jump.
  • Touch every Start, Sound, Next Level, and Restart button.
  • Make sure the page stays still while using the game buttons.
  • Publish version-6 and play its GitHub Pages link on a real phone.

Make it your own

Change a number. Change the game.

After the phone-ready game works, open version-6/game.js. The easy settings should be together near the top. Change only one value, save the file, refresh the browser, and try it. The included finished example uses the same settings.

game.js
const EASY_SETTINGS = {
  movementSpeed: 4.15,
  normalJumpHeight: 13.7,
  highJumpHeight: 17.2,
  gravity: 0.72,
  soundVolume: 1,
  applePowerSeconds: 5,
  nextStageDelaySeconds: 2.2
};
🏃

Movement speedTry 3 for slower or 5 for faster.

⬆️

Jump heightA larger number makes Jubee jump higher.

🔊

Sound volumeTry 0.5 for quieter or 0 for silent.

🍎

Apple powerChange 5 to choose how many seconds it lasts.

Ask Copilot to make easy settings

If your own game does not have the settings box, copy this prompt into Copilot Chat.

Prompt to give Copilot
Please put the easy-to-change game settings together near the top of game.js. Include movement speed, normal jump height, high jump height, gravity, sound volume, apple power time, and next-level wait time. Give each setting a clear name and a short note with a safe value to try. Update the rest of the game to use these settings. Keep everything else working.

Change levels and backgrounds

Near the top of game.js, each level has a theme named meadow, autumn, or moonlit. Change the word to use different scenery.

You can also replace the pictures in assets/backgrounds. Keep the same file names so the game can find them.

The one-change ruleChange one number or picture, save, refresh, and test. If you like it, keep it. If not, undo the change. This is how game designers experiment safely.

Share the learning page

Put this website on GitHub Pages

An adult should help with account creation and publishing. GitHub Pages can show this site online for free.

  1. Create a repository. Sign in at github.com, create a new public repository, and name it jubeeworld.
  2. Upload the site. Unzip the downloaded package and upload everything inside it. Keep index.html at the top level.
  3. Open Pages. Go to Settings → Pages. Choose Deploy from a branch, then choose main and /(root).
  4. Visit the site. Wait a few minutes. The address will usually be https://YOUR-USERNAME.github.io/jubeeworld/.
