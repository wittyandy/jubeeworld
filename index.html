Before you start

Make a new folder

Use a web browser, a text editor such as Visual Studio Code, and an AI assistant. Ask an adult for help when creating an online account or putting the game online.

  index.html

Save every working version. Copy the whole folder after each version and name it jubee-world-version-1, then 2, 3, 4, and 5. If something breaks, return to the last version that worked.

Talking with AI

Explain your idea naturally

Tell AI what you are making, what you want to change, which files you are sharing, and what should happen when it works. Short, clear sentences are best.

  1. AskCopy the prompt and share your current files.
  2. BuildPut the returned code in the correctly named file.
  3. TryOpen or refresh the game and test the new change.
  4. SaveKeep a new version only after everything works.

Version1

The beginning

Make the page and move Jubee

  • Cheerful game page
  • Start button
  • Temporary Jubee
  • Left and right movement
Prompt to give AI
I want to make a browser game called Jubee World. I have three empty files named index.html, styles.css, and game.js. Please make a cheerful page with the game title, a large game area, simple instructions, and a Start Game button. Draw Jubee as a caramel-colored shape with a cream-colored face. Let me move Jubee left and right with the arrow keys or the A and D keys. Jubee should stop when I release a key and should stay inside the game area. Give me the complete code for all three files and clearly label each file.
What should I test?
  • Open index.html and select Start Game.
  • Hold and release each movement key.
  • Make sure Jubee stays inside the game area.
Version2

Explore

Add jumping, a world, and a finish gate

  • Normal and high jumps
  • Platforms and gaps
  • A wider world
  • Finish gate
Prompt to give AI
Please improve my current Jubee World game. Add ground, raised platforms, and a few gaps. Jubee should jump with Space, W, or Up Arrow. If I press Up Arrow twice quickly, Jubee should jump higher. Jubee should land on platforms and should not jump again while already in the air. Make the world wider than the screen so the view follows Jubee as she moves. Put a wooden finish gate at the end. The level should finish only when Jubee touches the gate. Keep the movement from Version 1 calm and smooth. Give me the complete updated files that need to change.
What should I test?
  • Try every jump key and the double Up Arrow jump.
  • Land on every platform and cross every gap.
  • Make sure the level ends only when Jubee touches the gate.
Version3

Challenges

Add bones, an apple, and enemies

  • Golden bones and points
  • Five-second apple power
  • Three enemy types
  • Hearts and restart
Prompt to give AI
Please add fun challenges to my current Jubee World game. Place golden bones around the level and add points when Jubee collects them. Add an apple that makes Jubee larger for exactly five seconds, then returns her to normal size. Add squirrels, raccoons, and make-believe poison-ivy creatures. Jubee should defeat an enemy when she lands on it while falling. Touching an enemy from the side should take away one heart. Give Jubee three hearts and add a Restart button. Keep the jumps and finish gate working. Give me the complete updated files that need to change.
What should I test?
  • Collect bones and watch the score.
  • Eat the apple and count five seconds.
  • Defeat every enemy from above and test side contact.
  • Lose all hearts, restart, and reach the gate.
Version4

Bring it to life

Add pictures, smooth movement, and ten levels

  • Character and item pictures
  • Calm animation
  • Ten harder levels
  • Final celebration
Before asking: Put your pictures in an assets folder. Make smaller folders named jubee, squirrel, raccoon, ivy, bone, apple, and backgrounds.
Prompt to give AI
Please use my pictures in Jubee World. Replace the temporary shapes with the Jubee, squirrel, raccoon, poison-ivy, bone, and apple pictures I attached. Show the pictures in order so the actions look smooth. Use only two calm walking pictures for moving left and right, and do not make Jubee bounce up and down while running. Keep her size easy to see. Add ten levels. Each new level can be a little longer and can have more platforms, bones, and enemies, but every jump must still be possible. After Jubee touches the gate, show a Next Level button. After Level 10, show a celebration screen. Give me the complete updated files that need to change, and list the picture folders and names the game expects.
What should I test?
  • Watch Jubee stand, run, jump, and land.
  • Make sure running is calm and every picture appears.
  • Test the changes between several levels.
  • Finish Level 10 and check the celebration.
Version5

Finish and share

Add scenery, music, sounds, and final polish

  • Continuous scenery
  • Music and action sounds
  • Phone and tablet buttons
  • Final testing
Prompt to give AI
Please finish and polish my current Jubee World game. Add wide background pictures that move gently with the world and do not show obvious repeated edges. Use sunny, autumn, and nighttime scenery in different levels. Add cheerful background music and clear sounds for a normal jump, high jump, collecting a bone, eating an apple, growing larger, returning to normal size, defeating an enemy, getting hurt, and finishing a level. Add a Sound On or Off button. Add simple screen buttons so the game can be played on a phone or tablet. Keep all ten levels, calm movement, the five-second apple power, and the finish gate working. Give me the complete updated files that need to change.
What should I test?
  • Play all ten levels.
  • Check movement, jumps, platforms, items, enemies, hearts, gates, and sounds.
  • Turn sound off and on.
  • Try the game at different window sizes.

When something breaks

Tell AI exactly what happened

Problem-solving prompt
I am making Jubee World. When I [say what you did], the game [say what happened]. I expected [say what should happen]. Here are my current files. Please find the cause, keep all working features, and give me the complete corrected file that I should replace. Also give me three quick things to test.

Share the learning page

Put this website on GitHub Pages

An adult should help with account creation and publishing. GitHub Pages can show this site online for free.

  1. Create a repository. Sign in at github.com, create a new public repository, and name it jubee-world-learning.
  2. Upload the site. Unzip the downloaded package and upload everything inside it. Keep index.html at the top level.
  3. Open Pages. Go to Settings → Pages. Choose Deploy from a branch, then choose main and /(root).
  4. Visit the site. Wait a few minutes. The address will usually be https://YOUR-USERNAME.github.io/jubee-world-learning/.
🌐
No Canvas school files are needed.

The finished game uses a browser drawing screen that programmers call an HTML canvas. It is built into Chrome, Safari, Firefox, and Edge. It is not connected to Canvas LMS.
